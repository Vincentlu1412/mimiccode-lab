# 仿写式刷题实验室 · MimicCode Lab

> 不背答案，先模仿一小段，再亲手补完，最后合上提示独立重写。

一个零依赖、浏览器直接打开的 LeetCode 学习工具，专门服务于“边看边学边做题”的学习方式。

## 为什么做这个？

很多刷题工具只有两种状态：看题，或者提交。对初学者来说，中间最重要的过程——理解套路、模仿关键几行、逐步撤掉提示——往往没有被设计出来。

MimicCode Lab 把一道题拆成三个动作：

1. 看懂一个可迁移的解题套路
2. 在关键位置补全代码
3. 合上提示，自己重新写一遍

## 当前功能

- Python / C++ 双语言模板
- 分层提示：一次只给下一条
- 代码挖空与补全检查
- “合上提示，自己重写”模式
- 哈希表、滑动窗口、二分查找示例题
- 本地保存完成次数
- 响应式布局，手机和电脑都能用
- 零依赖、零构建，下载后双击 `index.html` 即可

## 四条学习路线

页面现在提供四条路线地图：

- **经典算法**：从数组、链表、树、图到动态规划
- **深度学习**：从 Tensor、反向传播到 Transformer Block
- **大模型**：从 Tokenizer、Attention 到 KV Cache、RAG
- **Agent 工程**：从结构化输出、工具调用到状态、重试和评测

目前算法区有可交互的示例题，其余路线先提供循序渐进的练习地图。后续会逐个补成带测试用例的代码实验，不把“看过概念”冒充成“已经掌握”。

## 快速开始

```bash
git clone https://github.com/Vincentlu1412/mimiccode-lab.git
cd mimiccode-lab
```

然后直接打开 `index.html`。也可以在项目目录运行一个本地静态服务器：

```bash
python -m http.server 8000
```

访问 http://localhost:8000。

## 学习建议

每道题建议按这个节奏练：

- 先看题意和“模仿对象”，不要急着看完整答案
- 每次只展开一条提示
- 补全后，用自己的话解释每个变量
- 点击“开始重写”，从空白重新写
- 第二天不看提示再做一次
